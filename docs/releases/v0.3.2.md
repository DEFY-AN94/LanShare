Fixes from the first check of 0.3.1 on a real iPhone: video and audio previews play, and the Home Screen app gets a way back from previews and downloads. A few smaller Home Screen fixes were found while checking these in the iOS Simulator. Checked with automated tests on macOS and Windows and in the iOS Simulator.

## What's new

- **Video and audio previews play**: since the first version, a video or audio file opened from the 文件 (Files) tab or a chat kept loading on the iPhone and never started. Previews now play and seek.
- **.m4a files play** instead of being offered as a download.
- **A way back in the Home Screen app**: a preview or 下载到「文件」 (Download to Files) used to open a view with no way back; only closing the app returned to LanShare.
  - Images, videos, audio and text files now open in LanShare's own viewer. Tap **关闭** (Close) at the top right to go back.
  - **下载到「文件」**, **下载** (Download) in a chat, and a tap on a PDF or any other file open a sheet. LanShare reads the file from the computer, then **打开分享** (Open share sheet) shows the share sheet, where you choose **Save to Files**. After saving or cancelling you are back where you were.
  - Files up to 200 MB can be saved this way, because the share sheet needs the whole file in the iPhone's memory. For a larger file the sheet says to download it in Safari.
  - A text file shows its first 1 MB. Chinese text saved on Windows (GB18030) shows correctly too.
  - In Safari, previews still open in a new tab and downloads go to Safari's downloads.
- **Taps after turning the iPhone**: in the Home Screen app, turning the phone to landscape and back could leave the page scrolled by the height of the status bar (an iOS issue). Every tap then hit what was drawn that far below the finger, until something scrolled the page or the app was closed. LanShare now puts the page back.
- **Closing a menu or dialog** by tapping beside it no longer also taps what is underneath, such as the 按名称筛选 (Filter by name) box, which raised the keyboard.
- **Dragging selected text or a picture** inside LanShare no longer leaves 松开即可上传到「…」 (Release to upload to "…") or 松开即可发送文件 (Release to send files) on the screen.
- **Network tip in the README**: the computer and the iPhone must be on the same network. A router can keep its Wi-Fi 7 (MLO) network or its guest network apart from the regular one.

The interface is in Simplified Chinese. The [README](https://github.com/DEFY-AN94/LanShare#getting-started) explains how to get started.

## Upgrading from 0.3.1

- Replace the app. Your paired devices, chat history, settings and certificate are kept, and phones stay paired.
- The Home Screen app loads the new version the next time it starts while it can reach the computer. If it still behaves as before, close it in the app switcher and open it again. There is no need to add the icon again.

## Before you install

- **Neither build is signed with a developer certificate** (the Mac app has only an ad-hoc signature).
  - Mac: macOS blocks the first launch. Allow it in System Settings › Privacy & Security › **Open Anyway**. When macOS asks whether LanShare may accept incoming network connections, click **Allow**, or the iPhone cannot connect. It asks again after each update.
  - Windows: SmartScreen shows "Windows protected your PC". Click **More info › Run anyway**. The installer needs administrator rights and adds a firewall rule that allows LanShare only on Private networks and only from the local subnet.
- **The Windows version has been tested only by CI**: unit and API tests, plus an automated silent install, firewall-rule check, start and uninstall. It has not been tested by hand yet. Those checks are listed under "Windows testing, later" in PLAN.md.
- **Not yet tried on a real iPhone**: the fixes in this version have been checked only in the iOS Simulator. Among the checks still to do are a video paused for more than 2 minutes and saving a file close to 200 MB from the Home Screen app. They are listed under "Real iPhone testing, later" in PLAN.md.
- The Mac build is for Apple silicon (arm64) only.
