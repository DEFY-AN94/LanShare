Fixes from checking 0.3.2 on a real iPhone: taps land where they should after turning the phone, `.ts` files open as text, and the share sheet says why when it fails. The rest of 0.3.2 passed that check: video and audio previews, a video paused for more than 2 minutes, LanShare's own viewer and saving files up to 200 MB in the Home Screen app, and the Mac's handling of profiles and disk images received from the phone. Checked with automated tests on macOS and Windows and in the iOS Simulator.

## What's new

- **Taps after turning the phone**: on an iPhone whose status bar sits at the top edge in one orientation and at the side in the other, turning it to the orientation with the status bar at the side could leave the Home Screen app drawn higher than where taps landed. A tap on a file hit the one above it, and the viewer's **关闭** (Close) could not be tapped; switching tabs put it right. LanShare now puts the page back once the turn has settled.
  - In that orientation iOS gives the Home Screen app less height than the screen and leaves a black band at the top or the bottom. That band is outside the page, so LanShare cannot fill it.
- **`.ts` files**: TypeScript source opens as text in Safari and in LanShare's viewer, instead of being offered as a video download. A real MPEG transport stream (a `.ts` video) is still treated as video.
  - When you save a `.ts` file, the share sheet still calls it a video and offers to save it as one, because iOS goes by the file name. **Save to Files** keeps the file as it is.
- **The share sheet**: **打开分享** (Open share sheet) is greyed out while the share sheet is on its way, and if sharing fails the message says why, for example 分享失败（NotAllowedError） (Share failed). Saving a file of almost 200 MB failed once that way without a reason.

The interface is in Simplified Chinese. The [README](https://github.com/DEFY-AN94/LanShare#getting-started) explains how to get started.

## Upgrading from 0.3.2

- Replace the app. Your paired devices, chat history, settings and certificate are kept, and phones stay paired.
- The Home Screen app loads the new version the next time it starts while it can reach the computer. If it still behaves as before, close it in the app switcher and open it again. There is no need to add the icon again.

## Before you install

- **Neither build is signed with a developer certificate** (the Mac app has only an ad-hoc signature).
  - Mac: macOS blocks the first launch. Allow it in System Settings › Privacy & Security › **Open Anyway**. When macOS asks whether LanShare may accept incoming network connections, click **Allow**, or the iPhone cannot connect. It asks again after each update.
  - Windows: SmartScreen shows "Windows protected your PC". Click **More info › Run anyway**. The installer needs administrator rights and adds a firewall rule that allows LanShare only on Private networks and only from the local subnet.
- **The Windows version has been tested only by CI**: unit and API tests, plus an automated silent install, firewall-rule check, start and uninstall. It has not been tested by hand yet. Those checks are listed under "Windows testing, later" in PLAN.md.
- **Not yet checked on that iPhone in this build**: the fix for taps after turning was tried there only from Safari's Web Inspector, and the iOS Simulator cannot show the case. The recheck is listed under "Real iPhone testing, later" in PLAN.md.
- The Mac build is for Apple silicon (arm64) only.
