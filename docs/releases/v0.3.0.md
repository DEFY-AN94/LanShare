Quick copy between the computer and the phone, both ways: notifications you can act on, an unread count, and the computer's clipboard sent to the phone in one click. Checked on a MacBook Pro (macOS 27.2) with a real iPhone; the phone side works as in 0.2.0.

## What's new

- **Notifications you can act on** (Mac):
  - A phone's text shows **复制** (Copy), which copies the whole text, not just the preview.
  - A file shows **打开** (Open), which opens it with its default app; programs and scripts are only shown in their folder.
  - Clicking a notification opens that conversation, also later from Notification Center, and also when LanShare was quit.
  - Windows: toasts have the same buttons while they are on screen.
- **Fewer interruptions**:
  - Per phone, the first two messages in a row notify. Later ones quietly update the second notification with **还有 N 条新消息** (N more new messages).
  - Settings › **通知** (Notifications) can leave message text out of notifications.
  - Deleting a message, clearing the chats, removing a device or opening the conversation takes its notifications back.
- **Unread count**: kept on the computer, so it survives restarts. It shows in the window, on the Dock icon, next to the menu bar icon after a hidden start at login, and in the Windows tray tooltip.
- **Send the clipboard to the phone**: the menu bar / tray menu's **发送剪贴板到「…」** (Send clipboard to …) sends what you copied on the computer to the most recent conversation, or to a device you pick:
  - text;
  - a screenshot;
  - a picture copied in another app, such as QQ or WeChat;
  - picture files copied in Finder.

  Other copied files are not sent; drag them into the chat window. LanShare reads the clipboard only when you do this.
- **Copy the latest text**: **复制最近收到的文字** (Copy latest received text) in the same menu puts the newest text from a phone on the clipboard.
- **Global shortcut** (optional, none by default):
  - Settings › **剪贴板** (Clipboard) records a shortcut that sends the clipboard from any app.
  - It needs at least two modifier keys, one of them Control or Command (Ctrl or Win). Combinations that would take over pasting, copying or typing are refused.
- **Launch at login on Windows**: Settings › **启动** (Startup). It stays on across upgrades, and Task Manager's switch is respected.
- **在文件夹中显示** (Show in folder) finds a chat attachment in an earlier shared folder too.

The interface is in Simplified Chinese. The [README](https://github.com/DEFY-AN94/LanShare#getting-started) explains how to get started.

## Upgrading from 0.2.0

- Replace the app. Your paired devices, chat history, settings and certificate are kept. Messages you already had count as read.
- Mac:
  - macOS asks once whether LanShare may send notifications: click **Allow**.
  - If LanShare's notifications were turned off before, turn them on in System Settings › Notifications › LanShare; Settings › **通知** says so.
  - Choose the **Alerts** style there if you want the buttons to stay on screen until you click.

## Before you install

- **Neither build is signed with a developer certificate** (the Mac app has only an ad-hoc signature).
  - Mac: macOS blocks the first launch. Allow it in System Settings › Privacy & Security › **Open Anyway**. When macOS asks whether LanShare may accept incoming network connections, click **Allow**, or the iPhone cannot connect. It asks again after each update.
  - Windows: SmartScreen shows "Windows protected your PC". Click **More info › Run anyway**. The installer needs administrator rights and adds a firewall rule that allows LanShare only on Private networks and only from the local subnet.
- **The Windows version has been tested only by CI**: unit and API tests, plus an automated silent install, firewall-rule check, start and uninstall. It has not been tested by hand yet. That includes this release's toasts with buttons, clipboard and launch at login. Those checks are listed under "Windows testing, later" in PLAN.md.
- The Mac build is for Apple silicon (arm64) only.
