First release of LanShare: messages and files between an iPhone and a Mac or Windows PC, over the local network only. The iPhone uses Safari, with no app to install, and nothing goes through the internet.

## What's in it

- **Messages**: an iMessage-style chat with a quick copy button on every text message; photos and files can be sent straight from the chat
- **Files**: the iPhone browses the shared folder on the computer (`~/LanShare` by default), and can upload, download, preview, rename and delete (to the Trash / Recycle Bin)
- **Pairing and security**: pair by QR code and approve on the computer after comparing a confirmation code; HTTPS all the way, with a local certificate authority you can install on the iPhone; only devices on the local network can connect, and phones can only reach the shared folder
- **New in M6 and M6.1**: the Windows version; a log file and **打开日志文件夹** (Open log folder) in Settings, with no message text or file names in it; deleted chats are really deleted from the database; automatic chat cleanup after 30 or 90 days; tighter isolation of the chat folders; pause survives a restart

The interface is in Simplified Chinese. The [README](https://github.com/DEFY-AN94/LanShare#getting-started) explains how to get started.

## Before you install

- **Neither build is signed with a developer certificate** (the Mac app has only an ad-hoc signature).
  - Mac: macOS blocks the first launch. Allow it in System Settings › Privacy & Security › **Open Anyway**. When macOS asks whether LanShare may accept incoming network connections, click **Allow**, or the iPhone cannot connect.
  - Windows: SmartScreen shows "Windows protected your PC". Click **More info › Run anyway**. The installer needs administrator rights and adds a firewall rule that allows LanShare only on Private networks and only from the local subnet.
- **The Windows version has been tested only by CI**: unit and API tests, plus an automated silent install, firewall-rule check, start and uninstall. It has not been tested by hand yet. Those checks are listed under "Windows testing, later" in PLAN.md. The installer is the exact file that CI built and install-tested for #4; the app's source is identical in this tag, since the later commits change only docs and scripts.
- The Mac build is for Apple silicon (arm64) only.
